# Plantillas

Jintia incluye tres temas HTML/Vivliostyle: `jintia-clasico` (una columna,
bloques de color por tipo pedagógico), `jintia-cuaderno` (cuadernillo A5 para
ejercicios) y `jintia-tecnico` (alta densidad de código, terminales y
diagramas). La plantilla activa determina componentes, bloques, ubicación de
márgenes y capacidades visuales declaradas en `themes/<id>/meta.json`.

Desde Desktop puedes previsualizar otra plantilla sin cambiar la activa. Desde
la CLI puedes revisar el catálogo con el diagnóstico y compilar usando la
plantilla declarada por el curso.
